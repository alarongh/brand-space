# Статистическая модель названий

Обновление 05.11.2026. Воспроизводимый источник — ранее сохранённая тысяча
публичных компаний по капитализации, срез 03.11.2026. Модель оценивает сходство
структуры с выбранными примерами. Данных о влиянии названия на успех бизнеса,
отрицательных примеров неудачных брендов и проверенного русского фонетического
корпуса в обучении нет. Балл не является вероятностью успеха или доступности знака.

## От узкой маски к модели

Прежняя выдача из 40 названий была следствием фиксированных AR в середине,
окончания N и пяти начальных букв. Это свойство конкретной конфигурации,
а не результат статистической оптимизации. Новый раздел по умолчанию использует
свободный поиск A–Z по длинам 4–9; диапазон можно изменить на любые длины 1–12.
Также можно явно применить текущие жёсткие правила каталога. Сайт остаётся общим
генератором без профилей моторного масла и скрытых запрещённых букв.

## Данные и веса наблюдений

По умолчанию используются 318 однословных форм без полностью прописного написания,
длиной 1–12. Пользователь может выбрать полные формы, отдельные слова или свой TXT.
В режиме слов каждая компания имеет суммарный вес 1, распределённый между её словами:
длинное составное название не получает большего веса только из-за числа слов.
Капитализация определяет исходную тысячу, но не вес наблюдения.

В обучении учитываются начала и окончания слов. Для сходства с источниками
используются все подходящие A–Z формы и слова сохранённой тысячи плюс собственные
примеры. Сопоставление с этим ограниченным списком не является поиском по реестрам.

## Шесть составляющих стоимости

Все стоимости неотрицательны. Меньшая суммарная стоимость означает лучший результат
в рамках модели. Веса редактируются отдельно:

| Компонент | Расчёт | Вес по умолчанию |
|---|---|---:|
| Буквенные переходы | Средняя отрицательная логарифмическая вероятность прямой и обратной символьной модели | 3 |
| Позиции букв | Вероятность буквы в позиции с учётом длины, относительного места и общего распределения | 0,7 |
| C/V-структура | Сглаженная частота полной маски при заданной длине, логарифм нормирован на длину | 1 |
| Повторы | Средняя стоимость частот максимума вхождений, разных букв, минимального и максимального интервалов | 0,5 |
| Длина | Сглаженная частота длины | 0,3 |
| Отличие от источников | Штраф при расстоянии Левенштейна 0–2 | 2,5 |

Символьная модель использует 1-, 2- и 3-граммы. Для символа x и контекста h:

```
P1(x) = (count(x) + 0.2) / (total + 27 × 0.2)
P2(x | h1) = (count(h1,x) + beta × P1(x)) / (count(h1) + beta)
P3(x | h2) = (count(h2,x) + beta × P2(x | suffix(h2))) / (count(h2) + beta)
```

В алфавит вероятностей входит конечный символ слова. Начальный контекст — ^^.
Обратная модель обучается на перевёрнутых словах. Вероятности неизвестных сочетаний
ненулевые: они ухудшают оценку, но не удаляют название. Позиционная модель использует
отдельное сглаживание; частоты структур и повторов — добавку 0,5.

Для близости к источникам штраф равен `((3 − d) / 3)²` при d = 0, 1 или 2;
при отсутствии формы в этом радиусе штраф 0. BK-дерево находит точные расстояния
в радиусе 2. Пустая графа близкой формы означает отсутствие формы в этом радиусе,
а не доказанную уникальность. Названия из источников остаются в полном каталоге.

Суммарная стоимость `C = Σ weight × cost`. Отображаемый индекс:
`100 × exp(−C / Σ weight)`. Это монотонная шкала индекса модели, не вероятность
коммерческого результата. В карточке показаны все составляющие, веса и вклады.

## Поиск без случайных выборок

Используется поиск по минимальной допустимой стоимости продолжения. Динамическое
программирование вычисляет нижнюю границу оставшихся аддитивных затрат по длине,
позиции и двум последним буквам. Дополнительные границы учитывают уже начатую
C/V-маску и возможные значения повторов. Эти границы могут быть оптимистичными,
но не хуже фактического завершения. Штраф сходства с источниками вычисляется
лениво у перспективных завершённых слов; его нижняя граница 0.

В очередь входят префиксы и ещё не подтверждённые/подтверждённые завершения.
Название попадает в результат, когда его полная стоимость не превышает границы
всех оставшихся ветвей. Поэтому вычисленные результаты образуют точный начальный
отрезок рейтинга по заданной модели, с обычной точностью вычислений JavaScript.
Жёсткие правила проверяет тот же движок, что обслуживает полный каталог.

Бюджет работы ограничивает количество обработанных узлов за запуск. Очередь
сохраняется в текущем вычислителе для продолжения. Лимит ожидающих ветвей останавливает
поиск явно; уже выданный отрезок корректен. При увеличении лимита можно продолжить.
Перезагрузка страницы или новый запуск создаёт новый расчёт; его можно воспроизвести
по сохранённым параметрам. Сохранение параметров не сохраняет всю очередь поиска.

## Разнообразие поверх индекса

После расчёта пула применяется жадная перестановка, основанная на MMR:

```
utility = modelScore − diversity × (60 × maxSimilarity + 4 × familyCount)
familyCount = selectedWithSamePrefix2 + selectedWithSameSuffix2
              + 0.25 × selectedWithSameCVMask
```

Сходство объединяет нормированное расстояние редактирования, Dice по триграммам
и совпадение первых/последних двух букв. Разнообразие 0 сохраняет порядок по модели;
большие значения сильнее разносят семейства. Это перестановка внутри вычисленного
пула, а не глобально оптимальное разнообразие среди 26¹² комбинаций. Пул можно
увеличивать и целиком выгружать в CSV; показанную выдачу — в TXT.

Отсутствующие в выдаче сочетания остаются доступны в полном каталоге. Полный каталог
и его полный CSV-экспорт не ограничиваются размером статистического пула.

## Проверка на отложенных данных

Компании разделены детерминированно по остатку ранга от деления на 5: 188 форм
для начального обучения, 51 для выбора сглаживания, 79 для независимой проверки.
Общие нормализованные формы исключаются из обучающей части соответствующего этапа.
Проверены beta = 1, 2, 5, 10, 20, 50, 100. На валидационной части минимальную
потерю дала beta = 50; она используется в приложении. Затем модель обучается на
обучающей и валидационной частях и оценивается на тестовых 79 формах:

| Модель | Бит на символ, меньше лучше |
|---|---:|
| Равномерная по символам | 4,7549 |
| Частоты отдельных букв | 4,2476 |
| Прямая/обратная сглаженная модель | 3,8992 |

После оценки рабочая модель обучается на всех выбранных формах. Эта проверка
измеряет предсказание буквенных последовательностей, не благозвучие и не спрос.

На воспроизводимом пуле 500 названий длиной 4–9, в первых 40:

| Метрика | По индексу | После разнообразия 0,65 |
|---|---:|---:|
| Разных C/V-структур | 9 | 16 |
| Среднее парное сходство | 0,3773 | 0,1802 |
| Наибольшее семейство одного начала из 2 букв | 28 | 6 |
| Наибольшее семейство одного окончания из 2 букв | 16 | 5 |

Это один диагностический прогон, не универсальная гарантия для любой конфигурации.
Подробные результаты и время текущего локального замера:
[statistical-validation.json](../reports/statistical-validation.json).

Независимые тесты полностью перебирают малые алфавиты и сравнивают состав и стоимость
всего рейтинга, проверяют прямой/обратный расчёт, допустимость границ, продолжение,
жёсткие правила, отсутствие дубликатов и сохранение вариантов при мягких штрафах.

Повторение:

```
node --test tests/*.test.js
node research/validate-ranking.js
```
