# Brand Space

Полный виртуальный каталог названий A–Z с применяемыми после выбора правилами.
Длины 1–12; по умолчанию 4–6 — **321 254 128** сочетаний. Никакого случайного
семплирования или ограничения общего числа результатов. Страница показывает 100 строк,
но произвольная позиция и все остальные результаты доступны через навигацию и экспорт.

## Использование

1. Без фильтров доступен весь выбранный диапазон A–Z.
2. «Профиль Моторное масло» включает Q/W/X/J и лимиты две гласные, две согласные,
   две одинаковые буквы подряд. Другие ограничения задаёт пользователь.
3. Можно указать буквы, префикс, подстроку, суффикс, запрещённые подстроки/окончания,
   C/V/?-шаблон, число гласных, позицию Y и точные стоп-слова.
4. После «Применить правила» вычисляется точное число вариантов. Можно перейти
   к произвольной позиции или названию, сохранить избранное и заметки.
5. Настройки и избранное сохраняются в браузере. Доступны JSON-копии и восстановление.
   Для TXT-словарей: одно латинское имя в строке, комментарии с #; совпадение точное.

Пользовательские словари не отправляются на сервер. На GitHub Pages публикуются только
исходники сайта. Браузерные данные не синхронизируются между устройствами: используйте
экспорт и импорт JSON. Не подключены проверенные словари известных брендов, имён,
нежелательных русских ассоциаций или частот n-грамм; полнота таких словарей не заявляется.

## Устройство поиска

Каталог — точное неявное представление исходного множества, а не материализованная таблица.
Каждому слову соответствует стабильный комбинаторный ID в общем A–Z-пространстве.
Ослабление фильтров возвращает прежде исключённые слова через повторное вычисление правил
на полном исходном множестве. Данные об исключённых словах не восстанавливаются из старой
SQLite-базы: сайт рассчитывает их из алфавита и номера.

- Aho–Corasick проверяет запрещённые подстроки, обязательную подстроку и окончания.
- Точные стоп-слова представлены Set и отдельным префиксным деревом; в подсчёте
  дерево позволяет исключать только целое слово, не запрещая его в составе другого.
- Динамическое программирование запоминает число допустимых продолжений состояния.
- Rank/select и префиксные счётчики находят нужный вариант без последовательного прохода
  миллионов предыдущих записей. Это навигация по порядковому номеру без SQL OFFSET.
- Большие количества, ID и позиции используют BigInt; порядок — длина, затем A–Z.
- Web Worker выполняет расчёт отдельно от интерфейса. Есть отмена и явный предел
  2 млн мемоизированных состояний; при превышении результат не выдаётся как полный.

Стоимость зависит от сложности правил и количества состояний, а не только от количества
слов. Набор с миллионами разных стоп-слов может потребовать много памяти; разделяйте
сложные расчёты по длинам. Произвольная регулярная грамматика и языковая модель не реализованы.

Хеш-таблица сама по себе ускоряет точное равенство, но не решает поиск по подстрокам
и структурным правилам во всём исходном пространстве. Поэтому основной индекс здесь —
переиспользуемые точные счётчики поддеревьев конечного автомата.

## Экспорт

«Всё в папку» использует File System Access API, если браузер его поддерживает.
Запись идёт блоками по 1000 строк, части по выбранному числу строк; полный результат
не накапливается в памяти. Файлы с данными не перезаписываются. При отмене текущая
часть прерывается; продолжение — с начала незавершённой части.

«Скачать часть CSV» работает через обычную загрузку. Следующая позиция сохраняется
в поле, каждую следующую часть можно скачать отдельным нажатием. При перезагрузке
точку продолжения можно восстановить из сохранённого состояния экспорта.
До 1 млн строк в части; это размер одного файла, а не лимит общего результата.
Экспорт триллионов вариантов физически требует соответствующих времени и места.
CSV содержит ID, название, длину, гласные, C/V, приблизительную транскрипцию и soft-признаки.

TO/TI/SO/MO, Y внутри, удвоения и транскрипция сами по себе не удаляют кандидатов.
Колонка частотности n-грамм пустая: проверенная модель не предоставлена.
Домены ru/com и товарные знаки РФ класса 4 требуют отдельной фактической проверки.

## Проверки и локальный запуск

Нужен современный браузер с Web Workers, ES modules и BigInt. Зависимостей нет.
Не открывайте index.html через file://; используйте локальный HTTP-сервер:

```sh
python -m http.server 8080 --bind 127.0.0.1
# http://127.0.0.1:8080
node --test tests/engine.test.js
```

10 тестов: независимый полный перебор малых алфавитов, все сочетания ограничений,
пересекающиеся паттерны, точные словари, rank/select, отсутствующие слова,
BigInt для 1–12, отсутствие удаления soft-вариантов и избыточные правила.
Старый профиль даёт **96 730 / 1 540 880 / 22 209 650** по длинам 4/5/6,
всего **23 847 260**, как исходная SQLite-база.
Подробные результаты конкретного запуска — в `reports/`.
