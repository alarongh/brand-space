# Brand Space — каталог названий

Сайт: https://alarongh.github.io/brand-space/

Полный виртуальный каталог сочетаний A–Z длиной **1–12 символов**. Все длины видны
над результатами; по умолчанию выбраны **3–12**. Можно выбрать отдельные длины,
например 3, 7 и 12. Готовых тематических профилей и заранее включённых фильтров нет.

## Собственные правила

Все поля необязательны. Незаполненное поле не ограничивает исходное множество.
После редактирования нажмите «Применить правила»; до этого показаны результаты
предыдущей применённой конфигурации, о чём сообщает строка изменений.

- Разрешённые/запрещённые буквы и собственный набор гласных.
- Точный префикс, подстрока, суффикс и C/V/?-шаблон.
- Несколько обязательных сочетаний: должны встретиться все либо хотя бы одно.
- Несколько допустимых начал или окончаний: подходит любое из соответствующего списка.
- Запрещённые начала, сочетания, окончания и точные названия.
- Буквы в конкретных позициях: 1 — первая, −1 — последняя, −2 — предпоследняя.
  Можно указать разрешённые и запрещённые буквы. Все правила позиций действуют вместе;
  название короче нужной позиции исключается.
- Лимиты гласных/согласных/одинаковых букв подряд, количество гласных, положение Y.
- Собственные пометки окончаний, которые добавляют признак, но не исключают варианты.

Разные группы условий объединяются через И. Внутри списков допустимых начал/окончаний
действует ИЛИ. Если одновременно указаны точный префикс и список начал, должны
выполняться оба условия. Шаблон C/V/? задаёт точную длину.
TXT-словарь: одно точное латинское название в строке, комментарии с #.
Словарь исключает целое название, а не все слова, содержащие его как подстроку.

## Паттерны 1000 компаний

На сайте доступна отдельная библиотека по топ-1000 компаний в рейтинге
[CompaniesMarketCap](https://companiesmarketcap.com/), срез 03.11.2026.
Она показывает частоты длин, масок C/V, первых/последних букв и n-грамм.
Можно сравнить полные формы, однословные названия и отдельные слова, явно выбрать
учёт Y и регистр источника. Любые маски переносятся в поиск только по выбору пользователя.
Самостоятельно задать несколько масок можно в поле «Набор масок C/V» (логика ИЛИ).

[Выборка, методика, результаты и ограничения](research/README.md).
Данные не доказывают причин успеха названий и не проверяют товарные знаки.

## Полнота и скорость

Каталог задаётся алфавитом, длинами и комбинаторным индексом. Он не требует файла
со всеми строками. Удалённых данных из старых выборок нет: изменение фильтров
вызывает новый точный расчёт по всему исходному пространству.

Aho–Corasick проверяет подстроки и окончания, префиксные деревья — начала и точные
исключения. Хеш-таблица ускоряет прямую проверку точных стоп-слов. Динамическое
программирование хранит число допустимых продолжений каждого состояния.
Rank/select пропускает ветви по их точному размеру и находит нужную позицию без
последовательного просмотра всех предыдущих вариантов. Порядок: длина, затем A–Z.
Все количества, позиции и стабильные ID вычисляются через BigInt.

Результаты не ограничиваются шорт-листом. 100 строк — размер одной страницы,
а не лимит выборки. Для длины 12 доступны все 95 428 956 661 682 176 сочетаний.
Расчёт выполняется в Web Worker. При сложности более 2 млн мемоизированных состояний
выдаётся явная ошибка; частичный результат не объявляется полным. В одном запросе
можно задать до 12 различных обязательных подстрок. Большие словари требуют памяти.

## Сохранение и экспорт

Правила, избранное и заметки хранятся в текущем браузере. Доступны JSON-копии
и восстановление. Общей синхронизации между устройствами нет; данные пользователя
не отправляются на сервер вычислений.

При переходе с первой версии прежние настройки не применяются автоматически.
Избранное сохраняется, прежние правила доступны отдельной JSON-копией. Новые
собственные настройки, включая отдельные длины, сохраняются между запусками.

Экспорт проходит всю выборку последовательно, блоками по 1000 строк, с разбиением
по выбранному числу строк. «Всё в папку» требует File System Access API; обычная
загрузка частей CSV доступна как запасной вариант. Позиция и правила экспорта
сохраняются; их можно восстановить отдельной кнопкой. Непустые файлы не перезаписываются.
Экспорт огромных множеств физически требует соответствующих времени и места.

Транскрипция побуквенная и приблизительная. Проверенные словари ассоциаций,
названий и частот n-грамм не подключены. Домены и товарные знаки автоматически
не проверяются. Никакого субъективного ранжирования или отбраковки по звучанию нет.

## Разработка и проверки

Зависимостей нет. Нужен современный браузер с ES modules, Web Workers и BigInt.
Для локального запуска используйте HTTP, а не file://:

```sh
python -m http.server 8080 --bind 127.0.0.1
node --test tests/*.test.js
node research/profile-variants.js
```

33 теста JavaScript и 4 теста Python: независимый полный перебор малых алфавитов, все новые группы условий,
позиции от начала/конца, пересекающиеся подстроки, точные словари, rank/select,
большие целые числа, необязательные пометки, миграция настроек и сохранение избранного.
Исторические количества и хеши сохранены как регрессионные проверки движка,
а не как встроенные профили приложения. Тесты автоматически запускаются на GitHub.

## Буквенные варианты, повторы и чтение

В анализе компаний появился конструктор вариантов. Маски C/V отсортированы по числу
компаний в выбранной группе. Для каждой можно получить все наблюдаемые шаблоны с одной
или двумя фиксированными буквами и задать минимальную поддержку. Поддержка шаблона
с двумя буквами считается по их совместному совпадению, без предположения независимости
позиций. В режиме отдельных слов компания учитывается один раз для каждого признака.
Примеры — названия из источника, а не рекомендации для использования.

Буквенная маска `?A??N?` фиксирует A на второй и N на пятой позиции. `?` означает любую
букву, C и V в этом поле означают сами буквы. Буквенные маски образуют объединение,
которое пересекается с набором структурных масок C/V и всеми остальными правилами.
Пересекающиеся шаблоны не создают дубликатов. Конструктор переносит один вариант,
заменяя текущие списки масок и длины; остальные пользовательские ограничения сохраняются.
Для более сложных буквенных условий есть редактор позиций от начала и конца.

Новые независимые правила:

- `maxSame`: максимум одинаковых букв **подряд**.
- `maxOccurrences`: максимум вхождений **каждой** буквы во всём названии.
- `minRepeatGap` / `maxRepeatGap`: число промежуточных букв между последовательными
  вхождениями одной буквы. AA → 0, ABA → 1, ABCA → 2. Три A в ABACA имеют интервалы
  1 и 1, а не 1 и 3. Названия без повторов удовлетворяют любому ограничению интервала.
  Минимум больше максимума допускает только названия без повторов.
- `minDistinct` / `maxDistinct`: число различных букв.
- `letterRules`: свои минимумы/максимумы количества и интервалов для конкретных букв.
  Все строки и общие ограничения применяются совместно. Чтобы требовать повтор,
  задайте для буквы минимум вхождений 2 или больше.
- `allowedConsonantPairs` / `allowedVowelPairs`: разрешённые направленные пары соседних
  букв одного класса. Пустой список не ограничивает. Список ST не разрешает TS.
  Класс определяется редактируемым набором гласных. Сочетания разных классов не ограничиваются.

Распределения повторов в конструкторе имеют кнопки переноса в условия. Для чтения можно
явно перенести пары CC/VV, наблюдавшиеся внутри выбранной семьи. Это структурные
условия, а не модель произношения: даже частая структура не гарантирует читаемость.
Никакое условие не включается автоматически. Необычные буквы и названия остаются
в исходном пространстве. CSV дополнен максимумом вхождений, числом разных букв и
минимальным/максимальным интервалом; отсутствие повторов обозначается пустыми интервалами.

Истории счётчиков и интервалов включены в точное состояние поиска. Для букв,
неразличимых для всех остальных правил, используется каноническая гистограмма состояний;
буквы, зафиксированные в масках, словарях или других условиях, сохраняют свою идентичность.
Это позволяет считать ограничение повторов на длине 12 без перебора всех слов.
Независимые тесты проверяют формулы перестановок и размещений по 26 буквам, полный
перебор малых алфавитов, совместные шаблоны, порядок, отсутствие дубликатов и rank/select.
Сложные сочетания правил по-прежнему могут превысить лимит состояний; это явная ошибка,
а не сокращение результата.
