# Проектный бриф

Нужен оригинальный латинский бренд моторного масла для РФ. Субъективная генерация
дала слишком много названий с ассоциациями с кофейнями, лекарствами, именами,
детскими или фантастическими персонажами. Пользователь заменил её полным
детерминированным каталогом, чтобы выбирать самостоятельно.

Последнее решение: расширить исходное пространство до всех возможных сочетаний,
а ограничения накладывать потом для подробного быстрого поиска. Опубликовать
веб-генератор на GitHub Pages, доступный по ссылке. Не формировать шорт-лист и
не удалять необычные варианты по субъективному звучанию.

Принята архитектура точного виртуального каталога: A–Z, длины 1–12, по умолчанию 4–6.
Все исходные строки воспроизводимы через комбинаторный индекс. Фильтры применяются
при поиске, исходное множество не сокращается. Счётчики состояний конечного автомата
заменяют повторные последовательные просмотры всего множества.

Профиль масла — включаемая настройка: Q/W/X/J, максимум две гласные, две согласные
и две одинаковые буквы подряд. Y по умолчанию согласная. Остальные фильтры выбирает
пользователь; списки точных нежелательных названий подключаются явно.

Soft-признаки TO/TI/SO/MO, Y внутри, удвоения и приблизительная транскрипция только
показываются. Пользователь может явно включить дополнительные ограничения.
Проверенной модели частот n-грамм и полных стоп-словарей нет; не изображать их наличие.
Пересекающиеся фильтры не считать независимыми сокращениями множества: количество
вычисляется для их совместного применения.

Сохраняются все подходящие варианты независимо от количества; CSV экспортируется
последовательно частями. Избранное и заметки хранятся в браузере, имеют JSON-копию.
Пагинация использует точные префиксные счётчики и rank/select, порядок — длина, A–Z.

Полная исходная SQLite-база v1.0.0 сохранена и проверена отдельно локально.
Этот сайт вычисляет более широкое множество и не требует скачивания SQLite.
Домены ru/com и товарные знаки РФ класса 4 — отдельная стадия; доступность без
реальной проверки не заявлять. Публикация сайта не является юридической проверкой.
